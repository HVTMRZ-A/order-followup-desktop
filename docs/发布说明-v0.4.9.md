本版汇总 v0.4.2 至 v0.4.9 的改进，适用于 Windows 10 / 11 x64。

- 计划总表恢复合并单元格、标题与订单父子关系，支持查看原表静态颜色及切换白底。
- 计划总表、订单管理和包材明细采用熟悉的表格操作：单击选择、直接键入替换、双击 / F2 编辑、Enter / Tab 提交、Esc 取消。
- 增加字体、字号、颜色、对齐、换行、行高与列宽调整，以及撤销 / 重做。格式工具默认收起并记忆状态，选中格和长内容更清楚。
- 计划表自动保存，支持 Ctrl+S、批量清空和移除记录；导出范围可选全部、当前或多个工作表。
- 待办支持搜索、高优先级筛选和直接确认；包材支持搜索和逾期筛选；每日跟进可以搜索勾选关联订单。
- 导入后定位新订单，统一完整计划表导出入口，减少重复弹窗和操作。
- 修复更新下载中断时的重试与续传，并增加官方 API 备用入口、完整性校验和下载日志。

验证：141 项自动化测试通过；Windows EXE 自检、发行包 SHA-256 校验和实际升级数据保留验证通过。升级保留本机订单及每日记录。
