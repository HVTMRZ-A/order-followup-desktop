# 订单跟进工作台 v0.4.0 使用说明

## 各工作区的数据联系

导航顺序：今日待办 → 订单管理 → 包材跟进 → 每日跟进 → 计划总表 → 设置与更新。

订单管理保存原单、订单和型号，是主数据来源。物料编码、数量、规格要求、单位、原单包材和 BOM 原始状态均保留；原单 BOM 状态不等同工程已确认。可导出原始文件，或用“补充原单资料”给旧记录补空白，不覆盖人工修订及确认状态。

接单登记后，合同、工程 BOM、分析和包材信息的未完成事项进入今日待办。事项前的确认框可直接确认合同、BOM、分析及包材信息；分析日期记录今天。计划加入类事项单击会打开加入预览，不能绕过确认；到料事项单击打开数量与日期填写窗口，不虚构已到数量。组头只负责展开 / 收起，逐项确认。

分析确认后自动生成关联订单的分仓检查待办，提醒在外部系统刷新并核查异常。每日三类记录可填写关联订单号（多个用逗号分隔）；未处理事项显示对应订单号。订单管理可查看该单的未解决跟进，并进入“关联每日跟进”。确认处理后待办消失，备注和订单关联保留。

包材跟进使用订单内对应型号及数量计算请购需求，同一订单的数量变化会影响需求计算；实际到料必须填写，不因勾选其他事项而自动视作到齐。

确认加入计划表后，行记录绑定订单与型号，可由计划行打开关联订单。绑定行的核心订单字段通过订单管理修改，再预览确认更新；“待更新关联行”默认不勾选，不擅自覆盖。手工原表行尚未确认关联时保留独立历史数据。

所有关联、原单副本及确认历史包含在本机备份中；这些工作区共享同一数据库，不需要在各处重复建单。

## 拖拽导入

订单管理和计划总表均可拖入 XLSX / XLSM / CSV。生产单及模板进入订单预览；完整计划总表自动进入总表导入预览，不会当作订单模板误读。一次可以拖多份订单文件；完整计划总表每次一份，与生产单分开拖入。

通用订单模板支持物料编码 / 物料代码 / 料号、产品要求、产品大类、单位、包材等明细列；自定义列保留在“原单完整明细”，原文件同时留存。生产单超过 200 行不再截断，超过明确支持上限时会提示拆分。

## 订单确认后加入计划总表

生产单导入或订单详情保存后，会打开“确认加入计划总表”预览。默认选择“最新”和适用的“包材资料未确定”；其余表按业务用途勾选，不自动把所有订单判成配件或家用机。

预览显示订单、型号、目标工作表、关键数值及处理结果。勾选适用表后，可逐行取消加入；点击“查看 / 补充所选行资料”补充料号、采购回复或发柜信息。确认后才追加新行或补充现有空白格；已有非空内容、原表公式不会覆盖。数量或料号冲突时留待人工核对。

缺少必需资料、目标表未导入、未确认加入的行会关联到该订单，显示在“今日待办”；主表可先加入而资料未齐时，同样保留补资料提醒。取消预览也不会丢失已登记订单，仍有“待确认加入计划总表”提醒。双击相关待办，或点击计划总表中的“订单加入总表 / 处理待办”，可再次预览处理。

补齐资料并重新确认后，已完成事项从待办移除。重复处理会检查现有订单和型号，不反复追加同一行。完整计划总表重新导入后，需要重新核对加入情况。加入的是本机计划表，最终使用“导出完整总表”另存 Excel。

## 完整计划总表（7 张可见工作表）

侧边栏“计划总表” → “导入计划总表”，选择完整 Excel 文件。预览确认后将全表保存在本机数据库，重开程序可继续编辑。

包含：最新、整体配件汇总、家用机订单、包材交期跟进、包材资料未确定、采购回复配件到料、出货计划。隐藏表不进入页面，也不进入导出工作簿。

导航只保留一个“计划总表”入口，这里显示历史数据、实际列和原表行号。“生产单导入”“新订单”和“订单跟进”操作均在这个入口。点击“订单跟进”可搜索已登记订单并进入详情确认；导入完整表不会覆盖已登记订单的跟进记录。

双击输入格或使用“编辑所选单元格”修改内容，保存后即写入本机；可以新增行，填采购回复、包材交期、出货安排等数据。空输入可清空单元格。

原表公式格只读。修改输入后，页面显示原公式并标记待重算；“导出完整总表”另存全部可见表，保留原公式、样式、图片、图表和外部链接，由 Excel 打开时重新计算。外部链接公式仍需原依赖文件。程序不会覆盖导入原件。

计划总表导入和导出在后台运行。完整表数据和源工作簿快照均包含在数据库备份及 JSON 备份中。替换导入前自动备份现有数据库。

## 第一次打开

解压 ZIP 到固定、可写的目录，双击 OrderFollowup.exe。真实数据不会随程序目录移动或更新而覆盖，数据目录是 `%LOCALAPPDATA%\OrderFollowupDesktop`。

## 今日待办：按订单折叠

待办清单按订单合并成一组：组头一行显示最高优先级、订单号、客户、待办数量、事项摘要和经办人。

- 组头前的 `－` 表示已展开，`＋` 表示已收起；**单击组头切换**，子项会缩进成 `└ 型号` 显示。
- 只有 1 条待办的订单直接平铺一行，不折叠。
- 双击任意一行（组头或子项）进入订单详情；折叠状态在刷新后保持不变。

## 订单总表：四个页面，对齐计划总表的四张 sheet

订单列表按总表的 sheet 结构拆成四个标签页，每个页面的列名和顺序都照抄对应 sheet：

| 页面 | 对应总表 sheet | 说明 |
| --- | --- | --- |
| 整机订单 | 最新 | 38 列全量，前面加「优先级」、后面加「跟进」 |
| 整体配件汇总 | 整体配件汇总 | 月份 / 客户 / 业务员 / 订单号 / 计划完成日期 / 产品大类 / 产品要求 / 公司型号 / 订单数量 / 未发货 / 包材 / 物料代码 |
| 家用机订单 | 家用机订单 | 计划序号 / 月份 / 订单号 / 物料代码 / 产品大类 / 规格 / 数量 / 产品交期 / 剩余数量 / 包材 / 备注 |
| 包材资料未确定 | 包材资料未确定 | 只列还没确认包材的型号；包材预留时间按交期前 15 天推算 |

四个页面共享顶部的搜索和筛选，双击任意行进订单详情。计划序列号在导入时填写或取号，存进订单，导出直接用。

**总表里另外四张 sheet 工作台不生成**，因为缺数据源：`26LTJX2034SP配件单`（要 BOM 明细）、
`采购回复配件到料`（要采购员、下请购单日期、到料回复）、`出货计划`（要柜号、毛重、危包资料）。
要用这几张，得先在工作台里补相应的录入项。

## 导入：拖拽或点按钮，都要你确认

三种方式都进同一个确认流程：

1. 把 `xlsx / xlsm / csv` **直接拖到窗口任意位置**，出现虚线遮罩和「松开即可识别导入」后松手；
   可一次拖多个文件，多文件会合并成一次预览。
2. 订单总表页「导入订单表」或今日待办页「导入订单」，可多选文件。
3. 生产单和导入模板都自动识别，不用先告诉程序是哪种。

解析完先弹「导入预览」：左边产品明细、右边计划总表映射、下面待核对项。**确认后才写库**，
取消则一行都不进。任一文件解析失败时整批不导入，并列出是哪个文件、什么问题。

## 登记和导入

在“订单总表”点“新订单”，填写订单号等信息，在“型号与确认项”添加至少一个型号及数量，然后保存。合同与销售订单分别记录单号和经办人。订单基本信息里还有客户编号、运输方式、订单属性、计划序列号四项，生产单导入时会自动填。

批量导入：先导出模板，将示例行替换为真实订单。必填列是“订单号、型号、产品数量”。同一订单多型号使用多行，订单基本信息保持一致。支持 XLSX 和 UTF-8/GB18030 CSV；旧版 XLS 先另存为 XLSX。订单号有前导零时，Excel 列必须设置为文本。

导入会先显示预览；存在重复订单、重复型号、无效数量或矛盾基本信息时整批不导入。初版不覆盖已有订单，请在订单详情中编辑。

## 导入生产单（自动识别）

“导入订单表”支持直接选《生产作业计划单》（整机生产单）。不用改格式，程序按表头文字定位：

- 头部：合同编号 → 订单号，客户编号 → 客订编号，订单属性、运输方式、计划完成日期、下单日期、经办人、注意事项；
- 明细表头：序号 / 产品大类 / 客户型号 / 公司型号 / 数量 / 单位 / 产品要求 / 包材 / BOM状态 / 物料代码；
- 表头行位置漂移、上方多少标题行都能认；多个型号逐行读出，同型号同物料编码自动合并数量；
- 表头数量与明细合计不一致、型号或数量缺失、日期无法解析时只提示不猜值，列在预览下方“待核对”。

预览分两页：产品明细、计划总表映射。映射页按《2026年新能源新计划》「最新」表的 38 列排列，电压 / 频率 / 功率从“产品要求”文字里提取（如 230V/50Hz/输出功率2kW → 230 / 50 / 2000），提不到就留空并提示。

“计划序列号”留空则不填；点“从计划总表取号”选一次总表，按 `X + 年份两位 + 5 位序号` 续当年最大号（如总表最大 X2601351 → X2601352），路径会被记住，下次自动带出。

确认后有两个出口：

- **确认导入**：只进工作台数据库；
- **导入并导出计划总表**：同时生成一份 xlsx，内含**四个 sheet**（最新 / 整体配件汇总 / 家用机订单 / 包材资料未确定），
  每个 sheet 的表头、列顺序与原总表一致，日期是日期型、数量是数字型，整表选中数据行粘到对应 sheet 末尾即可。
  **程序不会改写原计划总表**（29MB 带图表的总表用脚本回写会丢内容）。

订单总表页「导出计划总表」菜单可选“仅导出选中订单”或“导出当前筛选结果”，都是同一份四 sheet 文件。

## 编辑、删除与回收站

在“订单管理”选择对应型号行，点击“编辑订单”修改整单的客户、经办人、订单号、合同、销售订单和日期等资料；“编辑所选型号”直接修改该型号的数量、物料编码、产品要求和确认项。型号身份及包材关联保持，包材请购数量重新计算；保存后预览确认更新关联计划行。

“删除所选型号”同时移除该型号的包材、订单待办和计划行关联，其他型号保留。订单只剩一个型号时会转为整单删除确认。“删除整单”移除整个订单及其包材，解除每日跟进的订单关联，保留每日历史说明和其他订单。

删除前显示影响范围。默认保留计划总表的历史内容；勾选“同时清空计划总表中关联行的输入值”才会清空关联行输入值，行号、格式和公式保留，避免移动其他行。没有明确关联的历史行、与其他订单共用的行不会清空。

删除前自动备份，记录进入“回收站”。可恢复整单或单个型号及其包材；恢复型号时保留其他型号和订单的后续编辑。重复订单号或型号会阻止恢复，避免覆盖现有数据。恢复后计划表和每日关联需要重新确认；如需找回清空前完整计划内容，可使用删除前的数据库备份。

订单详情内的“移除所选型号”在保存订单后生效，取消编辑不会删除；保存后同样可从回收站恢复。

## 确认与优先级

- 整单 BOM、分析、包材信息、跟进完成按钮会确认当前全部型号；已经全选时再次点击可确认撤销。
- 双击型号可以独立勾选，设置实际分析日期。整单首次分析确认默认今天，已有分析日期保持不变。
- 合同：接单时间满 24 小时仍未确认，升为高优先级。仅录合同号不会代替勾选确认。
- 包材信息：分析日期起满 10 个自然日仍未确认，升为高优先级。
- “整单跟进完成”停止整单提醒；某型号完成停止该型号的包材提醒。初版完成属于人工确认，不强制关联实际出库。

## 包材

在订单详情“包材请购与到料”中新增包材，选择型号，填写单件使用量。系统按型号产品数量乘以用量自动得出请购数量，不扣库存、不自动加损耗或向上取整。

登记请购单号、采购经办人、预计到料日期和提醒日。提醒日留空则使用预计到料日期；两项均空则不会产生交期提醒。提醒日固定本机时间早上 09:00；过交期仍未到齐显示紧急。

分批到料时更新“累计已到数量”和“最近实际到料日期”，其余情况写入跟进备注。初版保存历史记录保存时间，不提供逐字段差异或完整分批到料台账。到齐自动停止本项提醒。

## 每日跟进

在外部系统刷新数据后，在工作台的“每日跟进”中将对应项目标为“无需跟进 / 需要跟进 / 已处理”，填写关联订单、经办人和处理说明。状态与备注编辑完成后自动保存。

此前日期的“需要跟进”事项会持续出现在今日待办；双击可以返回对应日期继续处理。

## 提醒运行条件

提醒不依赖在线服务器。程序每 30 秒检查一次；早上 09:00 后汇总通知当天高优先级事项。关闭窗口默认保留托盘运行；从托盘菜单“退出程序”才完全退出。

在设置中可以选择“登录 Windows 后自动启动”。电脑关机或程序彻底退出时无法准点提醒，下一次启动会补查未完成事项。程序内的优先级排序不依赖是否收到系统通知。

## 备份与更新

设置页可导出 JSON 备份，包含订单、包材、每日记录、保存历史、计划总表和回收站；恢复将替换当前数据，操作前会自动保留一份 SQLite 备份。仍可恢复旧版备份，旧备份不含回收站记录。

“检查新版本”连接公开 GitHub 仓库；存在新版时，由用户确认下载更新。下载校验 SHA-256，自动备份数据库，再原子替换程序。旧 EXE 保存为 `.previous.exe`；替换失败时尝试恢复旧文件。数据目录不受覆盖。

更新错误记录位于数据目录 `updates/update-result.txt`。当前没有新版本时显示当前版本已是最新。

## 初版范围

本地单机使用，不包含多人同步、云星空直连、自动采购下单、邮件/微信催办。分析和工程 BOM 仅记录确认，不在此软件中执行分析或编辑 BOM。
