# 订单跟进工作台使用说明

## 建议的日常顺序

1. 在“订单管理”导入生产单，核对明细后确认导入，再确认加入计划。完成后会直接定位新订单，不再弹出重复的成功确认框。
2. 到“今日待办”搜索订单或事项，需要时筛选高优先级；选中具体事项，点击下方显示的确认 / 填写按钮，也可点击事项前清晰的勾选框。
3. 在“计划总表”选择单元格，深蓝边框标出当前格，上方完整内容栏可查看、复制长内容。字体、颜色、行高列宽通过“展开格式设置”按需打开，收起后可多看几行。
4. 在“包材跟进”搜索订单、型号或包材，用“已逾期”查未到齐且超过预计交期的项目；选中后可核对还缺数量和日期，再编辑明细。
5. 在“每日跟进”点击“选择订单”，搜索、勾选要关联的订单，不必记住并手输订单号。状态、备注与关联继续自动保存。
6. 需要文件时，在“计划总表”点唯一的“导出”入口，选择全部、当前或自选 sheet。保存到本机仍使用 Ctrl+S 或保存按钮。

## 各工作区的数据联系

导航顺序：今日待办 → 订单管理 → 包材跟进 → 每日跟进 → 计划总表 → 设置与更新。

订单管理保存原单、订单和型号，是主数据来源。物料编码、数量、规格要求、单位、原单包材和 BOM 原始状态均保留；原单 BOM 状态不等同工程已确认。可导出原始文件，或用“补充原单资料”给旧记录补空白，不覆盖人工修订及确认状态。

接单登记后，合同、工程 BOM、分析和包材信息的未完成事项进入今日待办。事项前的确认框可直接确认合同、BOM、分析及包材信息；分析日期记录今天。计划加入类事项单击会打开加入预览，不能绕过确认；到料事项单击打开数量与日期填写窗口，不虚构已到数量。组头只负责展开 / 收起，逐项确认。

分析确认后自动生成关联订单的分仓检查待办，提醒在外部系统刷新并核查异常。每日三类记录可填写关联订单号（多个用逗号分隔）；未处理事项显示对应订单号。订单管理可查看该单的未解决跟进，并进入“关联每日跟进”。确认处理后待办消失，备注和订单关联保留。

包材跟进使用订单内对应型号及数量计算请购需求，同一订单的数量变化会影响需求计算；实际到料必须填写，不因勾选其他事项而自动视作到齐。

确认加入计划表后，行记录绑定订单与型号，可由计划行打开关联订单。绑定行的核心字段可以在计划格或订单管理中直接修改，计划格修改会同步订单；其他关联行再预览确认更新。“待更新关联行”默认不勾选，不擅自覆盖。手工原表行尚未确认关联时保留独立历史数据。

所有关联、原单副本及确认历史包含在本机备份中；这些工作区共享同一数据库，不需要在各处重复建单。

## 拖拽导入

订单管理和计划总表均可拖入 XLSX / XLSM / CSV。生产单及模板进入订单预览；完整计划总表自动进入总表导入预览，不会当作订单模板误读。一次可以拖多份订单文件；完整计划总表每次一份，与生产单分开拖入。

通用订单模板支持物料编码 / 物料代码 / 料号、产品要求、产品大类、单位、包材等明细列；自定义列保留在“原单完整明细”，原文件同时留存。生产单超过 200 行不再截断，超过明确支持上限时会提示拆分。

## 订单确认后加入计划总表

生产单导入或订单详情保存后，会打开“确认加入计划总表”预览。默认选择“最新”和适用的“包材资料未确定”；其余表按业务用途勾选，不自动把所有订单判成配件或家用机。

预览显示订单、型号、目标工作表、关键数值及处理结果。勾选适用表后，可逐行取消加入；点击“查看 / 补充所选行资料”补充料号、采购回复或发柜信息。确认后才追加新行或补充现有空白格；已有非空内容、原表公式不会覆盖。数量或料号冲突时留待人工核对。

缺少必需资料、目标表未导入、未确认加入的行会关联到该订单，显示在“今日待办”；主表可先加入而资料未齐时，同样保留补资料提醒。取消预览也不会丢失已登记订单，仍有“待确认加入计划总表”提醒。双击相关待办，或点击计划总表中的“订单加入总表 / 处理待办”，可再次预览处理。

补齐资料并重新确认后，已完成事项从待办移除。重复处理会检查现有订单和型号，不反复追加同一行。完整计划总表重新导入后，需要重新核对加入情况。加入的是本机计划表，最终使用“导出”生成 Excel 文件。

## 完整计划总表（7 张可见工作表）

侧边栏“计划总表” → “导入计划总表”，选择完整 Excel 文件。预览确认后将全表保存在本机数据库，重开程序可继续编辑。

包含：最新、整体配件汇总、家用机订单、包材交期跟进、包材资料未确定、采购回复配件到料、出货计划。隐藏表不进入页面，也不进入导出工作簿。

导航只保留一个“计划总表”入口，这里显示历史数据、实际列和原表行号。“生产单导入”“新订单”和“订单跟进”操作均在这个入口。点击“订单跟进”可搜索已登记订单并进入详情确认；导入完整表不会覆盖已登记订单的跟进记录。

单击只选中单元格，重复单击已选中格也不会进入编辑。选中后直接键入会替换原内容；双击或按 F2 可编辑原内容，F2 光标在原内容末尾。Enter 保存并向下选择，Tab 保存并向右选择，Shift+Enter / Shift+Tab 反向移动；移动后不会自动编辑下一格。移开焦点同样会保存，Esc 取消本次输入。Delete 清空选中的可修改内容，必填项和数据类型仍会校验。长文本可使用“详细编辑（长文本）”。可以新增行，填采购回复、包材交期、出货安排等数据；公式格只读。

订单管理同样支持格内直接修改客户、经办人、订单号、物料编码、型号、数量与要求等字段；整单合同和确认项仍可点击“编辑订单”。包材明细可直接改名称、单位、单件用量、累计已到数量、交期、提醒日和请购单号，需求与未到数量自动计算；其他包材字段使用“编辑包材详情”。每日跟进直接修改状态与说明，历史日期可选中后点“修改所选日期的跟进记录”。今日待办也有“修改所选订单 / 跟进”入口。

系统定时刷新不会打断正在编辑的订单或包材单元格。数据校验失败时恢复原值并显示“未保存”原因，不会把无效数量、重复型号或错误日期写入订单。

原表公式格只读。修改输入后，页面显示原公式并标记待重算；“导出”可选择工作表范围，保留所选表的公式、样式、图片及图表，由 WPS / Excel 打开时重新计算。外部链接公式仍需原依赖文件。程序不会覆盖导入原件。

计划总表导入和导出在后台运行。完整表数据和源工作簿快照均包含在数据库备份及 JSON 备份中。替换导入前自动备份现有数据库。

## 计划总表的保存、删除和导出

修改提交后会自动保存到本机。页面显示自动保存说明及最近保存时间；“保存到本机”或 Ctrl+S 还会提交正在输入、尚未按回车的单元格和待保存的行高列宽。无效数量或必填资料缺失时显示原因，不会提示该无效修改保存成功。保存到本机后，下次打开工作台可继续使用；它不会改写导入的原 Excel。

生成文件只保留一个“导出”入口，不另加重复的“另存为”。点击后先选择 **全部工作表 / 当前工作表 / 勾选工作表**，至少选择一张，再选择保存文件的位置。列表固定浅色背景、深色文字；深蓝方框内的白勾表示已勾选，浅蓝行只表示当前点中。下方显示实际导出范围或已勾选数量。表格顺序沿用原工作簿，不导出隐藏表。若公式引用未选中的表，导出后可能无法计算，请按需要选择全部表。

选中单元格或多个区域，点击“清空所选内容”或按 Delete，可一次清空输入值，保留格式和公式，并支持 Ctrl+Z 撤销。标题和表头不允许批量清空；关联订单的必填字段不能清成空值，失败时整次清空不写入，可改用“移除计划记录”。

要删除某条或多条计划明细，选中对应的行或明细格，点击“移除计划记录”，核对提示后确认；表格右键菜单及行号右键菜单也提供入口。此操作清空所选行的输入值，解除这些行的订单关联，保留空行、原行号、格式和公式，不把下方行上移，以免公式引用错位。其他明细还在共用的合并父项会保留。订单管理内的原订单、型号和包材不删除，后续重新加入计划仍需确认。

移除前自动备份，完成后可在本次打开期间 Ctrl+Z 撤销，也可 Ctrl+Y 重做；取消确认不改变数据。需要删除原订单或型号时，仍到“订单管理”使用对应删除功能和回收站。

## 第一次打开

解压 ZIP 到固定、可写的目录，双击 OrderFollowup.exe。真实数据不会随程序目录移动或更新而覆盖，数据目录是 `%LOCALAPPDATA%\OrderFollowupDesktop`。

## 今日待办：按订单折叠

待办清单按订单合并成一组：组头一行显示最高优先级、订单号、客户、待办数量、事项摘要和经办人。

- 组头前的 `－` 表示已展开，`＋` 表示已收起；**单击组头切换**，子项会缩进成 `└ 型号` 显示。
- 只有 1 条待办的订单直接平铺一行，不折叠。
- 双击任意一行（组头或子项）进入订单详情；折叠状态在刷新后保持不变。

| 页面 | 对应总表 sheet | 说明 |
| --- | --- | --- |
| 整机订单 | 最新 | 38 列全量，前面加「优先级」、后面加「跟进」 |
| 整体配件汇总 | 整体配件汇总 | 月份 / 客户 / 业务员 / 订单号 / 计划完成日期 / 产品大类 / 产品要求 / 公司型号 / 订单数量 / 未发货 / 包材 / 物料代码 |
| 家用机订单 | 家用机订单 | 计划序号 / 月份 / 订单号 / 物料代码 / 产品大类 / 规格 / 数量 / 产品交期 / 剩余数量 / 包材 / 备注 |
| 包材资料未确定 | 包材资料未确定 | 只列还没确认包材的型号；包材预留时间按交期前 15 天推算 |

这些辅助视图用于查看已登记订单及确认项，双击任意行进入订单详情。完整历史记录及全部可见工作表统一在侧边栏的“计划总表”中查看、编辑和导出；此处不再提供旧四表文件的重复导出入口。

## 导入：拖拽或点按钮，都要你确认

三种方式都进同一个确认流程：

1. 把 `xlsx / xlsm / csv` **直接拖到窗口任意位置**，出现虚线遮罩和「松开即可识别导入」后松手；
   可一次拖多个文件，多文件会合并成一次预览。
2. 订单管理页或今日待办页「导入订单」，可多选文件。
3. 生产单和导入模板都自动识别，不用先告诉程序是哪种。

解析完先弹「导入预览」：左边产品明细、右边计划总表映射、下面待核对项。**确认后才写库**，
取消则一行都不进。任一文件解析失败时整批不导入，并列出是哪个文件、什么问题。

## 登记和导入

在“订单管理”点“新订单”，填写订单号等信息，在“型号与确认项”添加至少一个型号及数量，然后保存。合同与销售订单分别记录单号和经办人。订单基本信息里还有客户编号、运输方式、订单属性、计划序列号四项，生产单导入时会自动填。

批量导入：先导出模板，将示例行替换为真实订单。必填列是“订单号、型号、产品数量”。同一订单多型号使用多行，订单基本信息保持一致。支持 XLSX 和 UTF-8/GB18030 CSV；旧版 XLS 先另存为 XLSX。订单号有前导零时，Excel 列必须设置为文本。

导入会先显示预览；存在重复订单、重复型号、无效数量或矛盾基本信息时整批不导入。初版不覆盖已有订单，请在订单详情中编辑。

## 导入生产单（自动识别）

“导入订单表”支持直接选《生产作业计划单》（整机生产单）。不用改格式，程序按表头文字定位：

- 头部：合同编号 → 订单号，客户编号 → 客订编号，订单属性、运输方式、计划完成日期、下单日期、经办人、注意事项；
- 明细表头：序号 / 产品大类 / 客户型号 / 公司型号 / 数量 / 单位 / 产品要求 / 包材 / BOM状态 / 物料代码；
- 表头行位置漂移、上方多少标题行都能认；多个型号逐行读出，同型号同物料编码自动合并数量；
- 表头数量与明细合计不一致、型号或数量缺失、日期无法解析时只提示不猜值，列在预览下方“待核对”。

预览分两页：产品明细、计划总表映射。映射页按《2026年新能源新计划》「最新」表的 38 列排列，电压 / 频率 / 功率从“产品要求”文字里提取（如 230V/50Hz/输出功率2kW → 230 / 50 / 2000），提不到就留空并提示。

“计划序列号”留空则不填；点“从计划总表取号”选一次总表，按 `X + 年份两位 + 5 位序号` 续当年最大号（如总表最大 X2601351 → X2601352），路径会被记住，下次自动带出。

确认导入后先登记到本机，再预览确认加入完整计划总表。缺资料的事项保留待办；取消加入预览也不丢失已登记订单。导入完成后自动进入订单管理并定位新单。

需要 Excel 文件时，请到计划总表使用“导出”选择工作表范围，不再经过“导入并导出”或旧的四表生成入口。原计划总表不会被覆盖。

## 编辑、删除与回收站

计划总表会还原原文件中的合并标题、纵向合并、列宽、行高、字号及对齐，正文仍统一白底。旧版已经导入的总表会从留存原件补齐显示格式，无需重新导入，工作台内已有修改保留。

同一订单用分隔线归组，型号列通过分支线显示其下属明细；选中后显示所属订单及明细范围。搜索订单或某个型号时会保留该订单整组明细和表头，便于查看上下文。合并格的编辑写入合并区域的首格，导出时保留原合并范围。

在“订单管理”选择对应型号行，点击“编辑订单”修改整单的客户、经办人、订单号、合同、销售订单和日期等资料；“编辑所选型号”直接修改该型号的数量、物料编码、产品要求和确认项。型号身份及包材关联保持，包材请购数量重新计算；保存后预览确认更新关联计划行。

“删除所选型号”同时移除该型号的包材、订单待办和计划行关联，其他型号保留。订单只剩一个型号时会转为整单删除确认。“删除整单”移除整个订单及其包材，解除每日跟进的订单关联，保留每日历史说明和其他订单。

删除前显示影响范围。默认保留计划总表的历史内容；勾选“同时清空计划总表中关联行的输入值”才会清空关联行输入值，行号、格式和公式保留，避免移动其他行。没有明确关联的历史行、与其他订单共用的行不会清空。

删除前自动备份，记录进入“回收站”。可恢复整单或单个型号及其包材；恢复型号时保留其他型号和订单的后续编辑。重复订单号或型号会阻止恢复，避免覆盖现有数据。恢复后计划表和每日关联需要重新确认；如需找回清空前完整计划内容，可使用删除前的数据库备份。

订单详情内的“移除所选型号”在保存订单后生效，取消编辑不会删除；保存后同样可从回收站恢复。

## 文字与单元格调整

计划总表、订单管理和包材明细上方都有格式工具。单击选中格后可以调整字体、字号（6–72 磅）、加粗、倾斜、下划线、文字颜色、填充颜色、左右及上下对齐和自动换行。拖动框选、按住 Shift 扩选，或按住 Ctrl 选择多个区域，可批量应用；点击行号或列字母可选整行或整列。一次最多处理 50000 格。Ctrl+B / Ctrl+I / Ctrl+U 可切换加粗、倾斜、下划线。

格式工具默认收起，点击搜索栏旁的“展开格式设置”使用；各工作区会分别记住展开状态，原有格式功能全部保留。选中格用深蓝边框标记，离开格子去点工具时仍保留位置提示。计划总表上方的“完整内容”栏只供查看、复制，原公式会标明只读；实际修改继续用双击或 F2。

调整尺寸有三种入口：拖动列标题之间或行号之间的边界；点击“行高 / 列宽”输入数值；或在行号、列标题上点右键。行高用磅，列宽用近似字符宽度；双击边界或点击“适应行高 / 适应列宽”可按内容自动调整。多行文字可先启用自动换行、调整列宽，再适应行高。

格式和尺寸自动保存到本机，重新打开仍保留。计划总表通过“导出”生成 Excel 时，会带上调整后的字体、颜色、对齐、换行、行高和列宽，所选表的数值、公式、图片及其它未修改格式保留。订单管理和包材明细的格式用于工作台显示，按订单、型号和包材标识保存，筛选后不会套错记录，不改写留存的原始生产单。

这些格式和尺寸调整均支持撤销、重做；一次批量应用算一次操作。点击“恢复原格式”只恢复所选格的初始显示格式，不清空内容。公式格和自动计算数量也可以调整显示格式，仍不能改写计算内容。格式修改不产生订单跟进或计划更新待办，也不会使公式因纯格式修改被标记待重算。格式和尺寸也包含在本机备份中。

关闭原表颜色后主动选择文字色或填充色，会重新开启颜色显示，便于看到本次修改。

## 原表颜色与撤销

计划总表默认显示导入 Excel 的固定单元格底色和字体颜色，支持 RGB、主题色及其明暗变化、索引色。有效表格范围内有颜色的空白格也会显示，修改或另存后保留原格式。以前导入的总表会从本机保留原件补齐显示颜色，不需要重新导入，已有修改保留。

取消勾选“显示原表颜色”可切回白底深色字，下次打开仍记住此选择。此开关只影响工作台显示，导出仍保留原表格式；不会重新开启交替行底色。当前不计算条件格式产生的动态颜色或图案填充效果，原有规则在导出文件中保留。

顶部“撤销 / 重做”按钮可以撤回已保存的表格修改；快捷键为 **Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做**。单元格正在输入时，快捷键先作用于尚未提交的文字。Esc 取消本格输入；确认保存后的修改才进入业务撤销记录。

支持计划总表、订单管理、包材明细的格内修改、文字格式、行高列宽、包材详情、计划新增行和每日跟进记录；同次计划修改涉及的订单字段及分析后的分仓跟进一起恢复，包材需求重新计算，其他关联计划行仍经确认更新。保留本次打开期间最近 100 次修改，退出后清空；撤销后再作新修改会清空重做记录。

重新导入计划总表或恢复备份后不能再套用旧表修改；相关字段被其他操作修改或删除时，也会阻止旧撤销覆盖新数据。删除整单或型号请使用“回收站”恢复；导入、删除和订单详情整单保存不属于本轮表格撤销范围。

## 确认与优先级

- 整单 BOM、分析、包材信息、跟进完成按钮会确认当前全部型号；已经全选时再次点击可确认撤销。
- 双击型号可以独立勾选，设置实际分析日期。整单首次分析确认默认今天，已有分析日期保持不变。
- 合同：接单时间满 24 小时仍未确认，升为高优先级。仅录合同号不会代替勾选确认。
- 包材信息：分析日期起满 10 个自然日仍未确认，升为高优先级。
- “整单跟进完成”停止整单提醒；某型号完成停止该型号的包材提醒。初版完成属于人工确认，不强制关联实际出库。

## 包材

在订单详情“包材请购与到料”中新增包材，选择型号，填写单件使用量。系统按型号产品数量乘以用量自动得出请购数量，不扣库存、不自动加损耗或向上取整。

登记请购单号、采购经办人、预计到料日期和提醒日。提醒日留空则使用预计到料日期；两项均空则不会产生交期提醒。提醒日固定本机时间早上 09:00；过交期仍未到齐显示紧急。

分批到料时更新“累计已到数量”和“最近实际到料日期”，其余情况写入跟进备注。初版保存历史记录保存时间，不提供逐字段差异或完整分批到料台账。到齐自动停止本项提醒。

## 每日跟进

在外部系统刷新数据后，在工作台的“每日跟进”中将对应项目标为“无需跟进 / 需要跟进 / 已处理”，填写关联订单、经办人和处理说明。状态与备注编辑完成后自动保存。

此前日期的“需要跟进”事项会持续出现在今日待办；双击可以返回对应日期继续处理。

## 提醒运行条件

提醒不依赖在线服务器。程序每 30 秒检查一次；早上 09:00 后汇总通知当天高优先级事项。关闭窗口默认保留托盘运行；从托盘菜单“退出程序”才完全退出。

在设置中可以选择“登录 Windows 后自动启动”。电脑关机或程序彻底退出时无法准点提醒，下一次启动会补查未完成事项。程序内的优先级排序不依赖是否收到系统通知。

## 备份与更新

设置页可导出 JSON 备份，包含订单、包材、每日记录、保存历史、计划总表和回收站；恢复将替换当前数据，操作前会自动保留一份 SQLite 备份。仍可恢复旧版备份，旧备份不含回收站记录。

“检查新版本”连接公开 GitHub 仓库；存在新版时，由用户确认下载更新。下载校验 SHA-256，自动备份数据库，再原子替换程序。旧 EXE 保存为 `.previous.exe`；替换失败时尝试恢复旧文件。数据目录不受覆盖。

更新错误记录位于数据目录 `updates/update-result.txt`。当前没有新版本时显示当前版本已是最新。

v0.4.2 起，连接重置（如 WinError 10054）、超时或传输中断时最多尝试 4 次，并切换 GitHub 官方 API 下载入口。支持服务器允许的断点续传；服务器忽略续传请求时从头下载，避免拼接错误。已下载的部分在失败后保留，再次点击“检查新版本”可继续；完成后仍需大小及 SHA-256 均匹配才能替换程序。

下载阶段会显示连接、重试、已下载数量和百分比。设置页的“打开更新日志”可查看 `updates/download-log.jsonl`，其中记录连接阶段、已下载字节数、断连/超时和校验结果；不记录订单和临时签名链接。“打开手动下载页”可用于旧版无法自动完成更新时获取最新版，使用原数据目录即可保留订单。

## 初版范围

本地单机使用，不包含多人同步、云星空直连、自动采购下单、邮件/微信催办。分析和工程 BOM 仅记录确认，不在此软件中执行分析或编辑 BOM。
