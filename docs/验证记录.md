# v0.1.0 初版验证记录

验证环境：Windows 11 x64，Python 3.13.12，PySide6 6.12.0。

## 已完成

- 21 项自动化测试通过：合同 24 小时边界、包材信息第 10 天边界、交期 09:00 边界、型号独立确认、整单确认、到齐停止提醒、十进制数量计算、导入校验与整批事务、备份恢复、界面保存、更新版本和文件校验。
- 打包后的 Windows EXE 自检退出码为 0：5 个页面正常构造，Excel 模板可导入为 1 单 2 型号，SQLite 可读取，HTTPS 所需 SSL 可加载。
- 在隔离测试目录由实际打包 EXE 发起更新并退出，新 EXE 重启完成自检：替换后哈希与新程序一致，旧 EXE 保留，订单、每日跟进状态和备注保持，更新前数据库备份存在。
- 界面截图使用独立虚构数据检查，发布程序不预置这些测试订单。

## 验证范围

尚无公开的后续版本，因此没有跨两个正式发布版本的在线升级记录。已验证更新文件校验和实际替换重启流程；后续版本发布时仍需运行数据迁移与升级回归。

通知依赖 Windows 系统通知设置和程序运行状态，未验证关机期间触发通知（此场景不支持）。数据为单机本地保存，未测试多人同时操作同一数据库。
