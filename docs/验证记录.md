# v0.4.0 验证记录

## v0.4.0

- 61 项自动化测试通过：原有流程、完整计划表保留与编辑、导入去重与冲突、原单字段和文件留存、待办直接确认、拖拽文件分流、订单与计划行关联、分析后分仓检查、每日记录关联订单及数量变更后的确认更新。
- 使用实际提供的生产单核对物料编码、数量、规格要求、单位、包材和 BOM 原始状态，物料编码可在订单管理直接显示。
- 提供的计划总表 7 张可见表在导入及另存后有效值和公式一致，9 个图片 / 图表 / 绘图文件保持；隐藏表不导出。
- 原路径下的 v0.4.0 Windows EXE 自检退出码为 0；6 个工作区、Excel 支持和 HTTPS 支持正常。
- 使用已发布 v0.1.0 EXE 发起更新到 v0.4.0，验证旧程序退出、新程序重启及订单、每日记录、旧 EXE 和数据库备份保留。
- 发布包不含测试数据库、真实订单或原单文件。
