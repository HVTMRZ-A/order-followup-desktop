# v0.4.9 实际试用与改进

使用 Windows 桌面窗口逐步操作体验副本；订单、经办人和跟进资料为虚拟数据。计划表采用原文件的本机测试副本，正式订单库和原文件未改动。文件选择在体验环境使用 Qt 对话框，正式程序保留 Windows 原生文件选择器。

| 试用时的障碍 | 这次的改进 |
| --- | --- |
| 格式工具长期占两行，业务记录被挤到下方 | 三个表格工作区默认收起格式工具，随用随展开并分别记忆状态 |
| 待办小勾选框不醒目，依赖双击才能找操作 | 明确勾选框轮廓，增加按事项显示的处理按钮及所属订单详情入口 |
| 待办多了只能滚动找，定时刷新容易丢选中位置 | 增加搜索和高优先级筛选，保留仍存在的选中事项及滚动位置 |
| 长内容被格子截断，难以复制核对 | 增加计划格完整内容栏，显示坐标及公式只读状态；选中格有明确边框 |
| 包材缺少搜索，也不能直接找逾期项目 | 增加搜索、逾期筛选和选中包材的剩余数量、预计交期提示 |
| 每日记录要记住订单号再手输 | 增加可搜索的订单勾选窗口，筛选时保留已选订单，仍按订单标识保存关联 |
| 导入时有旧四表导出按钮，和完整总表流程不一致 | 移除重复入口，统一为导入、确认加入、在计划总表导出 |
| 导入结束还要关闭成功弹窗，再手动查新单 | 使用页面提示，并直接定位新订单和明细，便于核对物料编码、数量 |

实际窗口中已完成：搜索 BOM 待办并处理虚拟工程确认；选择并保存每日关联订单；查看所选格边框和长内容；导入一单两型号，核对物料编码，再确认加入四行计划记录；打开并核对工作表导出范围窗口。无需修改正式业务数据。

保留原业务规则：合同、BOM、分析、包材确认方式及时间规则；计划加入需确认；包材需求计算、公式保护、撤销、删除备份和导出范围不变。后续使用者反馈仍可能发现不同分辨率或大批量数据下的问题，本次不将试用视为完整的人因验证。
